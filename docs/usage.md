# Локальный запуск

## 1. Перейти в проект

```bash
cd /Users/tony/Projects/codex-workspace/nenoybot
```

## 2. Создать виртуальное окружение

```bash
python3 -m venv .venv
source .venv/bin/activate
```

## 3. Установить зависимости

```bash
pip install -r requirements.txt
```

## 4. Настроить `.env`

```bash
cp .env.example .env
```

Можно оставить `NENOYBOT_DEFAULT_GOAL` пустым. Тогда CLI спросит цель при запуске.

## 5. Запустить CLI

```bash
python app/main.py
```

Команды внутри CLI:

```text
/goal новая цель
/exit
```

## 6. Запустить тесты

```bash
pytest
```

## Telegram online worker

Создай бота через `@BotFather`, затем добавь токен в `.env`:

```text
TELEGRAM_BOT_TOKEN=123456:token
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-5.5
DATABASE_URL=postgresql://...
```

Запуск:

```bash
python -m app.telegram_bot
```

Команды:

```text
/start
/goal результат + срок
/clear_goal
```

Кнопки:

```text
🎯 Задать цель
✅ Отчёт
🔥 Пинок
📌 Меню
🧹 Сбросить цель
```

Для цели и отчёта нажми кнопку и следующим сообщением напиши обычный текст.

Для хостинга используй тот же start command:

```bash
python -m app.telegram_bot
```

## Neon memory

В Neon Console создай проект и скопируй connection string. Для Railway добавь её в `Variables`:

```text
DATABASE_URL=postgresql://user:password@host/dbname?sslmode=require
```

При старте worker сам создаст нужные таблицы:

```text
nenoy_user_state
nenoy_messages
```

## Поддержка и ежедневные сообщения

1. `/support` включает поддержку, сохраняя цель и историю тренера.
2. Один раз подтвердите пояс и 1–3 времени: `/support_schedule 09:00,13:00,17:00 Europe/Moscow`.
3. `/support_schedule` показывает состояние; доступны `/support_pause`, `/support_resume`,
   `/support_off`, `/support_now` и `/coach`.

Пояс задаётся в IANA-формате и не угадывается. Слоты старше 30 минут не догоняются.
Неоднозначная доставка отмечается `uncertain` и не повторяется вслепую: exactly-once между
Postgres и Telegram технически не обещается.

## Наблюдения и служба заботы

Нажмите **«Мои наблюдения по проекту»**, затем выберите **«📝 Поделиться наблюдением»**
или **«🛟 Нужна помощь»**, пришлите текст до 3000 символов, проверьте preview и нажмите
«📨 Отправить». Черновик хранится в Postgres и восстанавливается после перезапуска, но
удаляется примерно через 24 часа. `/cancel` сразу удаляет черновик и ничего не передаёт. Команда получает только выбранный
текст, тип, номер, время и режим — не переписку, цель или расписание. Submitted-обращения
хранятся до ручного удаления администратором; автоматический срок удаления пока не реализован.
Служба заботы не является экстренной службой.

Telegram `429` повторяется один раз строго после указанного `retry_after`; `403` считается
заведомо недоставленным (`blocked`). Только неоднозначный сетевой исход получает статус
`uncertain` и не повторяется вслепую.
