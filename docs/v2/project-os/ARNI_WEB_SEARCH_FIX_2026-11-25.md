# Арни — проверяемый веб-поиск, 25.11.2026

## Причина инцидента

По скриншоту и агрегатным логам: 25 ноября 09:05 МСК Арни обработал Instagram Reel без возможности открыть видео. В 09:06 уточнение «Яндекс пин, найди всю инфу» дошло до webhook, получило очередь direct, но worker закончил в `SILENCE` с безопасным кодом `model_flagged_sensitive_content`. Конкретный внутренний текст ответа модели в логи намеренно не записывается, поэтому объяснение, почему она выставила этот флаг, — гипотеза, а не доказанный факт.

Исходный transport Responses отправлял `tools=[]`. Внешнего веб-поиска в Арни действительно не было. История группы при этом продолжала сохраняться.

## Изменения

- Отдельный web_research для прямых публичных запросов и небольших сообщений со ссылкой; он не строит психологические профили и не сохраняет содержимое сайтов в личную память.
- Запрос «Яндекс пин, найди всю инфу» попадает в публичный поиск *до* психологической assessment-фазы; PIN-код банковской карты и другие приватные данные не отправляются в поиск.
- Используется OpenAI Responses `web_search`, `tool_choice=required`, `include=web_search_call.action.sources`. Tool billing резервируется до вызова: максимум 4 × $0.01, в observe без дневного лимита сохраняется учёт.
- Проверенные URL извлекаются из ответа провайдера, а не из сгенерированного текста. HTTP, localhost, внутренние и приватные адреса исключаются. В Telegram публикуются только HTTPS-источники.
- Поиск ссылки из недавнего контекста возможен только для того же автора, группы и темы, при повторной проверке прав и актуальности исходных сообщений.
- При отсутствии подтверждённых источников — честный отказ утверждать факты; при сбое публичного поиска — короткое уведомление на прямой запрос. Не обходятся stop/forget и ограничения доступа.
- Старые личные отчёты продолжают разбираться по прежнему движку. Автоматические поиски ограничены короткими сообщениями со ссылками; никакого безлимитного обхода сайтов при любой реплике нет.

## Приёмка

1. Синтетический тест публичного устройства и оригинального текста «Яндекс пин».
2. Синтетический follow-up с Instagram URL из предыдущей авторизованной реплики.
3. Отсутствие подтверждения — никаких выдуманных характеристик.
4. Тест на запрет отправки PIN-кода/приватных URL в поисковик.
5. Провайдерный HTTP mock: `tools=[web_search]`, `tool_choice=required`, источники из действия и citation annotations.
6. Денежная резервация поиска раньше HTTP, стоимость включена в AI ledger, при ошибке без автоматических платных повторов.
7. Полная регрессия `tests_v2`, миграция 0019 на PostgreSQL; развернуть только после PASS.
8. Проверить реальный ответ GPT-5.4 по публичному устройству и ссылкам, отправку в Telegram и состояние NeNoi.

Важно: Telegram-бот не получает произвольный браузер с авторизацией. Закрытые Instagram-видео, приватные страницы или удалённые публикации могут оставаться недоступными. Результаты поиска не должны выдаваться за просмотр ролика. Нет обещания импортировать прошлые сообщения или читать приватные аккаунты.
